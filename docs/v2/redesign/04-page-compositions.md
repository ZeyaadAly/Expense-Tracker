# Page compositions

| Page | New composition | Preserved behavior |
| --- | --- | --- |
| Dashboard | Net-position canvas with disclosed assets/debt; concise period movement; three-account preview with all-accounts link; recent ledger and compact upcoming datebook | Exact current balances, period selector, archived inclusion, recent5/upcoming bounded server data, independent recovery |
| Accounts | Net-position band and typed instrument rows with balance/action edges; lazy transfer workspace behind Transfers | Active/archive, create/edit/archive/restore, permanent locks and authoritative refresh |
| Account detail | Current position as anchor; opening/income/expense context; paired transfer movements; disclosed metadata and lazy Transfers | Same read model, edit/lifecycle dialogs and transfer history; no invented transaction-detail feature |
| Transactions | Compact search/common filters, More filters disclosure and dense ruled ledger; phone records with a clear money edge | Search submit, all filters, chips, Next/Previous cursor history, CRUD and recovery |
| Transfers | Paired source/destination review and movement rows | Atomic API behavior, card semantics, CRUD and uncertainty inspection |
| Recurring | Concise schedule definitions with disclosed full details/filters beside the date-anchored expected timeline | Filters, create/edit/pause/resume/archive, null/exhausted dates and separate expected/posted meaning |
| Analytics | Primary period totals/flow and spending breakdown; disclosed derived metrics, savings, exact data, income, account movements and expected commitments | Presets/custom range/account filter, null rates, backend totals, chart equivalents and stale scope |
| Budgets | Category-led spending-pressure rows with spent/limit/remaining and explicit status; threshold/period details disclosed | Month selection, CRUD, backend threshold/status, actual percent above100% |
| Goals | Serious target/saved/remaining composition with progress and disclosed account/date reference | Manual progress, completion/reopen/archive, above100% and lifecycle rules |
| Settings | Quiet profile/preferences/account/category/security sections with a category directory loaded only on expansion | Profile and categories CRUD/lifecycle, read-only preferences, reset/sign-out, many-category stress |
| Auth | Branded financial statement composition and a calm form column; compact product masthead on phone | Login/register/recovery/reset, password visibility, associated errors and safe redirects |

No new financial features, theme switch, notification, projection, report/export or P1 work is introduced. The current Dashboard has no connected chart/Budget/Goal preview; those are not faked or added by this redesign.

The [current refinement report](06-density-and-loading-refinement.md) supersedes the original default-view density and sizing.
