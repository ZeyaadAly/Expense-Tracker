| Page | New composition | Preserved behavior |
| --- | --- | --- |
| Dashboard | Net-position canvas with explicit assets/debt; adjacent period movement; account instrument rail; recent ledger and upcoming datebook | Exact current balances, period selector, archived inclusion, recent5/upcoming bounded server data, independent recovery |
| Accounts | Net-position band and typed instrument rows with balance/action edges; transfer ledger below | Active/archive, create/edit/archive/restore, permanent locks and authoritative refresh |

| Recurring | Scheduled definition rail beside the date-anchored expected timeline | Filters, create/edit/pause/resume/archive, null/exhausted dates and separate expected/posted meaning |
| Analytics | Period result band; paired flow/savings plots; exact data; category distributions and account movements; distinct expected-commitment section | Presets/custom range/account filter, null rates, backend totals, chart equivalents and stale scope |
| Budgets | Category-led spending-pressure rows with spent/limit/remaining and explicit status | Month selection, CRUD, backend threshold/status, actual percent above100% |
| Goals | Serious target/saved/remaining composition with progress and quiet account reference | Manual progress, completion/reopen/archive, above100% and lifecycle rules |
| Settings | Quiet profile/preferences/account/category/security sections with a readable category directory | Profile and categories CRUD/lifecycle, read-only preferences, reset/sign-out, many-category stress |
| Auth | Branded financial statement composition and a calm form column; compact product masthead on phone | Login/register/recovery/reset, password visibility, associated errors and safe redirects |

No new financial features, theme switch, notification, projection, report/export or P1 work is introduced. The current Dashboard has no connected chart/Budget/Goal preview; those are not faked or added by this redesign.
